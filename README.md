# Reunión Familiar Lotería · versión mobile

Invitación digital optimizada para móvil con temática de lotería mexicana.

## Cambios principales

- Diseño **mobile-first**.
- Se quitó la imagen secundaria después de “Música en vivo”.
- El contador ahora usa **marcos tipo carta de lotería**.
- Nuevas cartas ilustradas para:
  - Fecha
  - Hora
  - Lugar
  - Música
  - Menú
  - WhatsApp
  - Banco
- La galería se redujo a **una sola imagen**.
- Textos ajustados para que no se desborden en celular.
- Confirmación y cuota solo al final.
