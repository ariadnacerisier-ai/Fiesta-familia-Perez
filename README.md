# reunion-familiar-loteria-mobile-cambios

Versión actualizada de la invitación web con estos cambios:

- Se eliminó la imagen principal tachada.
- La cuenta regresiva ahora usa como fondo las cartas:
  - El corazón
  - La luna
  - El gallo
  - La mano
- Los detalles del evento usan imágenes individuales para:
  - Fecha
  - Hora
  - Lugar
  - Música
- El menú quedó en 3 bloques separados:
  - Tamales con mole
  - Arroz
  - Carnitas
- Optimizado para visualización móvil.
