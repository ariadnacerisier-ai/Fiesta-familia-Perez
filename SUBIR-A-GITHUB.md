# Subir a GitHub

1. Sube el contenido de la carpeta `reunion-familiar-loteria-mobile-cambios` a la raíz del repositorio.
2. Verifica que `index.html` quede en la raíz.
3. En GitHub ve a:

`Settings > Pages`

4. Configura:

- **Source**: Deploy from a branch  
- **Branch**: `main`  
- **Folder**: `/(root)`

5. Guarda los cambios y espera el despliegue.

## URL esperada

`https://savetheclick.online/reunion-familiar-loteria-mobile-cambios/`
