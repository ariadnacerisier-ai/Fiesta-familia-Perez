# Subir a GitHub

1. Crea un repositorio nuevo o actualiza uno existente.
2. Sube el contenido de la carpeta `reunion-familiar-loteria-mobile` a la raíz.
3. Verifica que `index.html` esté en la raíz.
4. En GitHub, ve a:

```text
Settings → Pages
```

5. Configura:

```text
Source: Deploy from a branch
Branch: main
Folder: /(root)
```

6. Guarda y espera el despliegue.
